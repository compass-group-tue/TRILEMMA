# TRILEMMA project site (draft)

Site: https://compass-group-tue.github.io/TRILEMMA/ (once GitHub Pages is enabled) · Code: https://github.com/compass-group-tue/TRILEMMA-ENV

Static site for the paper *TRILEMMA: How Agents Choose Between Honesty, Confidentiality, and Task Completion*.
No build tools or server needed: open `index.html` directly, or serve the folder (GitHub Pages works as is).

- `index.html`: the landing page. It has the setup, a staffing mini-game, a replay of a real morning (`main`, dspro s6), the
  trilemma triangle, the per-seat matrix of `main`, the confidentiality and honeypot charts, the
  motivated-reasoning stepper (paper Fig. 3), the findings and the citation.
- `traces.html`: a trace viewer for every run cited in the paper, 815 runs in 25 settings. Pick a setting in the sidebar.
  - Groups: `main` and its variants; `honeypot` and `no-avoidance-baseline`; the four `dislike-*` settings;
    `emily-available`; the 12 `discussed-*` settings; and `S1`/`S2` (unseeded cooperation).
  - Views: timeline, messages with reasoning drawers, per-agent log, and prompts (every agent's system prompt and user prompt).
  - Each conversation starts with its pre-seeded workspace history, collapsed.
  - Every tool call shows its full arguments and full result. Results load when opened.
  - Judge overlays appear where the paper has them:
    - deception (no-CoT, 3 replicates) plus the CoT acknowledgment check: `main`, `main-high-conf`, `main-high-conf-honest`;
    - disclosure (3 replicates): `main`, `main-high-conf`;
    - the honeypot judge: `honeypot`.
  - Deep links: `traces.html#<setting>/<model>_s<seed>&view=chat`. Runs of `main` also keep the short form
    `traces.html#<model>_s<seed>`.

## data/

Generated by `trilemma/site/build_site.py` and `trilemma/site/build_mr.py` in the TRILEMMA-ENV repository:

    python -m trilemma.site.build_site --runs-root RUNS --outputs-root OUTPUTS --out data
    python -m trilemma.site.build_mr   --runs-root RUNS --outputs-root OUTPUTS --data data

All files are JSONP, so the pages also work from `file://`. Run, results and world files are gzip+base64 and are decoded in
the browser.

| path | what |
|---|---|
| `index.js` | settings, one row per run with the seat labels, and the `main` matrix of the landing page |
| `worlds/<world>.js` | the pre-seeded Slack workspace of one world, stored once and shared by every run that starts from it: conversations, the messages before the run, the user directory, and tool-result fragments that recur across runs |
| `runs/<setting>/<model>_s<seed>.js` | one run: the messages posted during the run, every agent turn (reasoning, text, tool calls with full arguments), board moves, system and user prompts, and judge results |
| `results/<setting>/<model>_s<seed>.js` | the full tool results of that run, loaded on demand |
| `mr.js` | motivated-reasoning examples (mr7 judge) for the landing page |

The `discussed-*`, `emily-available`, `S1` and `S2` settings keep every non-killed rollout, as the paper counts them. Where that
gives two rollouts of one seed, the second gets a letter suffix; currently only `S1/glm53flash_s0b`.

Inside tool results, Slack messages are stored as references to the world or run messages and expanded by the viewer. The
`team` and `client_msg_id` identifier fields are left out.

The site does not include the per-turn input payloads, the wake and notification logs, token usage, wall-clock
times, the full run configuration, the world's call log or the model proxy dumps.

## Names and themes

The rollouts use the workspace names (Priya, Nadia, Matthieu, Rafael, Helena, Ines, Zofia, Callum). The pages show the
paper's placeholders (Alice, Carol, Bob, Dan, Mary, Emily, Fiona, George), and the trace viewer has a toggle.
`?theme=light|dark` forces a theme, which is handy for screenshots.

The landing page's matrix and its three counters are computed from the judge outputs. Its other charts (confidentiality,
honeypot, the trilemma-move counts and the Fig. 3 reasoning ladder) show the paper's numbers, which are produced by the
analysis scripts in TRILEMMA-ENV.
