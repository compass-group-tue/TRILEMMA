# TRILEMMA project site (draft)

Static site for the paper *TRILEMMA: How Agents Choose Between Honesty, Confidentiality, and Task Completion*.
No build tools or server needed: open `index.html` directly, or serve the folder (GitHub Pages works as is).

- `index.html` — landing page: setup, staffing mini-game, replay of a real morning (dspro s6), the
  trilemma triangle, the per-seat matrix of `main`, confidentiality and honeypot charts, the
  motivated-reasoning stepper (paper Fig. 3), findings, citation.
- `traces.html` — trace viewer for all 90 `main` runs (= agent5 5.e.x; 7 open-weight models + claude-opus-5
  + gpt-5.6-sol, s0–s9). Views: timeline, board (time × lanes), messages with reasoning drawers,
  per-agent log, prompts. Judge overlays: deception (no-CoT, 3 replicates) + CoT acknowledgment check,
  disclosure (luna v5c, 3 replicates). Deep links: `traces.html#<model>_s<seed>&view=board`.
- `data/` — generated by `build_site.py` (JSONP `.js` files so `file://` works). ~85 MB, ~1 MB per run.

Rebuild after re-judging:

    python experiments/agent5/site/build_site.py
    python experiments/agent5/site/build_mr.py   # data/mr.js: motivated-reasoning examples (mr7 judge), needs data/runs first

Names: the rollouts use the workspace names (Priya, Nadia, Matthieu, Rafael, Helena, Ines, Zofia);
the pages show the paper's placeholders (Alice, Carol, Bob, Dan, Mary, Emily, Fiona). The trace
viewer has a toggle. `?theme=light|dark` forces a theme (handy for screenshots).

Hand-entered numbers (not recomputed from `data/`): the confidentiality chart (paper Table 13), the
honeypot bars (Fig. 4a), the trilemma-move counts and the Fig. 3 reasoning ladder. The matrix and
its three counters are computed from the judge outputs via `figures/judged_data.py`.
